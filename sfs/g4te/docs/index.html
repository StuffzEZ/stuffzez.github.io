g4te documentation

what is g4te?

g4te (pronounced "gate") is the free ai gateway for everybody. unified access to multiple ai providers including aws bedrock, openai, anthropic, google vertex, and more through a single endpoint. whether you're a developer or hobbyist, g4te makes it easy to use any ai without managing multiple api keys.

key features

  • • unified api across all major ai providers
  • • powered by new-api backend and stuf_y's free server

your api key

how to get your key

  1. log in through the sfs dashboard
  2. go to g4te settings in your profile
  3. click "generate new key"
  4. copy and save your key securely

keys are never stored in plaintext. we only store encrypted references.

using your key

# example request with curl
curl https://g4te.stufy.qzz.io/v1/chat/completions \
  -H "Authorization: YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4", "messages": [{"role": "user", "content": "hello"}]}'

detail logging in

authentik integration

g4te uses stuf_y's free server authentik instance for authentication. this means:

  • • single sign-on across all sfs services
  • • secure passwordless login options
  • • audit logs for all activity
  • • configurable session timeouts

login flow

  1. navigate to the auth portal
  2. choose your preferred login method (password, oauth, etc.)
  3. complete multi-factor authentication if enabled
  4. you'll be redirected back to g4te with an active session

topping up balance

understanding credits

each ai provider has different pricing. your g4te balance covers usage across all providers based on their individual rates. check the dashboard for real-time usage tracking.

adding funds

balance top-ups are handled through the sfs billing interface. cryptocurrency and traditional payment methods may be supported depending on availability.

note: some basic usage is provided free of charge as part of g4te's mission.

linking apps

connecting third-party apps

g4te supports standard openai-compatible apis, meaning most tools that work with openai will work with g4te out of the box:

chatbot frameworks

chainlit, langchain, llama-index

desktop apps

continue, poetry, jan

mobile apps

chatbox, imessage extensions

web platforms

next.js, n8n, make.com

configuration

set your base url to https://g4te.stufy.qzz.io/v1 and use your g4te api key instead of your provider key. model names follow standard conventions like gpt-4, claude-3-opus, etc.

planned features

advanced rate limiting, team workspaces, custom routing rules, webhooks for usage alerts, and dedicated support channels. stay tuned for updates.
